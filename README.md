# Personal Developer Portfolio

A minimal, responsive developer portfolio built with React, JavaScript and CSS to showcase my projects, technical skills and experience working with digital products.

## About the Project

This portfolio is a personal project created to develop my frontend skills, practise working with React, and present my journey into software development.

With a background in digital marketing, website management, community platforms and quality assurance, I'm interested in the intersection of software development, user experience and problem-solving.

The website brings together my coding projects and transferable experience in one place.

## Getting Started

Follow these instructions to run the project locally.

### Prerequisites

Install [Node.js](https://nodejs.org/) (LTS recommended) and npm.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/teresa-portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd teresa-portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal, usually `http://localhost:5173/`.

## Available Scripts

| Command | Description |
|---|---|
| `npm run dev` | Starts the local development server |
| `npm run build` | Creates an optimised production build |
| `npm run preview` | Previews the production build locally |
| `npm run lint` | Runs ESLint, if configured in the project |

## Deployment

The project has been deployed using [Netlify](https://www.netlify.com/) but can be done using another hosting provider that supports Vite.

For Netlify, use the following build settings:

- **Build command:** `npm run build`
- **Publish directory:** `dist`

Connect the GitHub repository to enable automatic deployments when changes are pushed to the configured branch.
